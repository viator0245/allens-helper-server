알렌의 서재 조건 해석 API

한국 의사 국가고시 문제를 분석하는 AI 중계 서버입니다.

API Endpoint

POST /api/interpret

Request Body

{
  "questionText": "문제 지문",
  "explanationText": "해설 내용"
}

Response

{
  "data": [
    {
      "phrase": "원문 문구",
      "short": "요약",
      "long": "설명"
    }
  ]
}

사용 제한

  • 지문: 최대 5,000자
  • 해설: 최대 10,000자
